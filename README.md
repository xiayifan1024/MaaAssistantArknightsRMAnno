# MAA Remove Guide and Announcement

> Do not let anger and arrogance ruin this project.

基于 [MAA（MaaAssistantArknights）](https://github.com/MaaAssistantArknights/MaaAssistantArknights) 的个人修改版本，主要精简教学指引与公告提示，供自己与好友学习交流使用。

[本项目仓库](https://github.com/xiayifan1024/MaaAssistantArknightsRMAnno) · [原项目仓库](https://github.com/MaaAssistantArknights/MaaAssistantArknights) · [使用文档](docs/zh-cn/manual/README.md)

## 修改范围

- 移除首次启动的教学指引流程。
- 调整公告与强制提示的展示行为，减少使用过程中的打断。
- 后续根据实际需求精简界面与功能，保留日常使用所需的核心功能。

具体行为以本仓库当前代码为准。

## 更新策略

版本号跟随上游，使用 `v上游版本-rmanno.序号` 区分本项目发布，例如 `v6.21.4-rmanno.1`。

- 优先保持游戏资源更新与同步能力。
- 软件更新以跟进上游大版本为主，按需合并其他修改。
- 本项目独立维护，更新节奏可能与原项目不同。
- 主要更新 windows x86 软件，如有需要后续编译
